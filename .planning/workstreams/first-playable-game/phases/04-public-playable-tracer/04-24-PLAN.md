<objective>
Gap 1 of 04-VERIFICATION.md: make the private-path controls fail closed at every public sink (T-04-11, T-04-15, T-04-18, T-04-20; review findings CR-01, CR-02, CR-08, CR-09, and the private-path and receipt parts of IN-04; validation escalation E1).

Today `_forms()` enumerates a few encodings, so U+2215, U+2044, double-percent, mangled and HFS forms survive `redact`, and only the bare-username token in `scan_public` catches them for `$HOME`. Non-home roots are unprotected. The sinks scan `ensure_ascii` JSON, where `\uXXXX` text defeats NFKC folding. `main()` crashes with `AttributeError` before writing a receipt, and two CLI modes print raw exception text.

This plan replaces encoding enumeration with one canonical form, matched from the same canonicalization of each root, and routes every sink and printed error through it. Generic roots (`/Users/`, `/tmp/` and the rest) are anchored to path starts so that the wider canonical matching does not turn benign repository text into receipt failures. It keeps the existing D4-01..D4-03 product behavior unchanged; only qualification tooling changes.

Purpose: make the publishable receipt, summary and printed output trustworthy for HOST-02 and QUAL-03 evidence.
Output: canonical matcher, updated sinks, failing-first regressions for every CR-01 variant and for CR-02/CR-08/CR-09.
</objective>
