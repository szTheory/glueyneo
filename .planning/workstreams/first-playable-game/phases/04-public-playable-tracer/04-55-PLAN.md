Purpose and decision (METHODOLOGY.md applied; roles: closure-gate integrity, maintainability, test cost, receipt stability):
- Option A, exact ATX rule only: fixes the reported case, but leaves the same defect class for a backtick fence look-alike (CommonMark 0.31.2 §4.5: a backtick fence's info string may not contain a backtick, example 145), which also ends collection early and hides rows.
- Option B, chosen: end the table only where GFM certainly ends it (blank line; ATX heading opener per CommonMark 0.31.2 §4.2, examples 62-64 show `####### foo`, `#5 bolt` and `#hashtag` are not headings; blockquote; exact fence opener) and read every other line as a row (GFM 0.29-gfm §4.10: the table is broken at the first empty line or the beginning of another block-level structure; example 202 shows a pipe-less line becoming a row). Any disagreement then errs toward reading an extra line as a row, which fails closed as `malformed threat row`, never toward hiding a row. Other block starts (list items, thematic breaks, HTML blocks) were already read as rows and stay so; that direction is fail-closed by construction.
- Option C, a full Markdown parser dependency: rejected (AGENTS.md small, flat dependency trees; the checker is standard-library only, T-04-40).
- Planning-time check (not plan evidence): no line in any tracked `*-SECURITY.md` register changes classification between the old and new pattern, so the real registers keep their counts.
