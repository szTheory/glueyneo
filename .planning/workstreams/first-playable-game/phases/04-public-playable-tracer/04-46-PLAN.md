<objective>
Fix G3WR-05 test-first with docs: the provenance window is anchored to the original review, so it cannot order dispositions of gap-round findings.

Purpose: the G3WR-05 docstring claims a cited verdict "postdates the review it answers". For gap-round findings that is false, because the gate never reads the gap review. Each finding is therefore bound to the review round that raised it, using a mechanical anchor (the commit that published that round's review file), and descent is made strict. The claim is narrowed to what that proves.

Scope: split from the original 04-45 on checker advice (scope ratio); G3WR-02/G3IN-01 in tools/independent_review.py follow in 04-47.

Output: fixed tools/verify_playable.py, tests and docs.
</objective>
